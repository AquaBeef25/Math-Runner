# Meadow v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the Meadow look like Kenney's own platformer art: a layered ColorGrass background, rolling ramps and water pools, object-like platforms (pillar ledges, bridges, "!" blocks), coins (+10), bees, and background scenery — while every level stays generated, deterministic and finishable.

**Architecture:** `BackgroundTheme` becomes a list of parallax layers that `ParallaxBackground` builds at runtime. `LevelPlanner` gains ramps, water, platform styles, coins, bees and backdrop props (still pure, still checked by `JumpReach`, still emitting the reference `Jumps` plan). `PlayerController` follows slopes. New small components (`RampPiece`, `WaterPool`, `Coin`, `Bee`) are instantiated by `LevelBuilder`.

**Tech Stack:** Unity 6000.3.11f1, C#, URP 2D, Kenney *New Platformer Pack* + *Background Elements Remastered* (CC0), Unity Test Framework.

**Spec:** `docs/superpowers/specs/2026-10-18-meadow-v2-design.md` (keeps the rules of `2026-10-18-meadow-world-design.md`)

## Global Constraints

- CLAUDE.md conventions (namespaces, `[SerializeField] private`, tunables in ScriptableObjects, `GameEvents`, no YAML hand-edits, ScriptableObject scene/asset refs via setter + read-back).
- Meadow background = **ColorGrass** look as parallax layers. Coins **+10 points**, coin counter in the HUD, coins **don't change star ratings**. Falling into water = −1 heart + respawn (like a pit). "!" blocks are platforms only.
- Ramps use the **long** grass ramp (1 tile of rise per 2 tiles of run, ≈27°); no 45° ramps for running up.
- Encounter stretches: no gaps and no water; ramps, spikes, walkers, pillars allowed (unchanged rule otherwise).
- Every new hazard has a planned take-off in `Jumps`; coins and props never within 1.5 units of a hazard; sorting order: background < backdrop props < terrain < hazards/coins < player.
- PlayMode: at most one filtered run per task. Revert `LiberationSans SDF - Fallback.asset` before commits. Commit `Kenney/Background/` (the pack used here) but not `Additional_Pack/`, `Emotes/`, `Enemies/`. Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Running over a ramp crest at speed 6** → the runner must stay on the ground (no launch) and keep its speed → Task 3 `RunnerStaysGroundedOverACrest`.
2. **A jump that starts on a ramp** → still clears what follows (take-off on a slope gives the normal jump) → Task 3 `JumpFromARampReachesFullHeight`.
3. **Respawn after falling into water** → back on solid ground at the checkpoint, exactly one heart lost → Task 5 `WaterCostsOneHeartAndRespawns`.
4. **A coin placed where grabbing it means hitting a bee or spike** → coins only on safe arcs → Task 7 `CoinsSitOnSafeArcs`.
5. **Coins changing the star rating** → stars depend on answers only → Task 7 `CoinsDontChangeStars`.
